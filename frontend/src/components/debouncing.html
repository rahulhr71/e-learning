🚀 JavaScript Debouncing Guide

1. Basic Debouncing Example

Debouncing क्या है?

Debouncing एक technique है जो function को तब तक execute नहीं करती जब तक user कुछ समय (delay) तक input देना बंद न कर दे।


Real Life Example: जैसे elevator में button दबाने के बाद कुछ seconds wait करता है कि कोई और floor select करे या नहीं।

Normal API Calls: 0
Debounced API Calls: 0
// Simple Debounce Function function debounce(func, delay) { let timeoutId; return function(...args) { // Previous timeout को clear करें clearTimeout(timeoutId); // New timeout set करें timeoutId = setTimeout(() => { func.apply(this, args); }, delay); }; } // Usage const debouncedSearch = debounce(searchAPI, 500); // User typing पर: input.addEventListener('input', debouncedSearch);

2. Real Search Example

Search Calls Made: 0
// Search API Function function searchMovies(query) { if (!query) return; console.log(`🔍 Searching for: ${query}`); // Fake API call simulation setTimeout(() => { displayResults(`Results for "${query}"`); }, 300); } // Debounced search (300ms delay) const debouncedMovieSearch = debounce(searchMovies, 300); // Event listener searchInput.addEventListener('input', (e) => { debouncedMovieSearch(e.target.value); });

3. Button Click Debouncing

Normal Button Clicks: 0
Debounced Button Clicks: 0
// Button click handler function handleButtonClick() { console.log('💾 Saving data...'); // API call simulation } // Debounced button click (1 second) const debouncedButtonClick = debounce(handleButtonClick, 1000); normalBtn.addEventListener('click', handleButtonClick); debouncedBtn.addEventListener('click', debouncedButtonClick);

4. Debouncing के फायदे

🚀 Performance: Unnecessary API calls कम हो जाती हैं
💰 Cost Saving: Server resources और API costs बचती हैं
⚡ Better UX: User experience smooth रहता है
🌐 Network: Network traffic कम होता है
// Common Use Cases: 1. Search Box: User typing के दौरान 2. API Calls: Form validation में 3. Button Clicks: Double-click prevention 4. Scroll Events: Infinite scrolling में 5. Resize Events: Window resize के दौरान // Advanced Debouncing with immediate execution: function debounce(func, delay, immediate = false) { let timeoutId; return function(...args) { const callNow = immediate && !timeoutId; clearTimeout(timeoutId); timeoutId = setTimeout(() => { timeoutId = null; if (!immediate) func.apply(this, args); }, delay); if (callNow) func.apply(this, args); }; }
