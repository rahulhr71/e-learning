📚 Lookup क्या है?

MongoDB $lookup:

$lookup MongoDB का aggregation stage है जो SQL की JOIN के समान काम करता है। यह दो या ज्यादा collections को connect करके data को combine करता है।


Real Life Example: जैसे आपके पास Users की list है और Orders की अलग list है, तो $lookup से आप देख सकते हैं कि कौन से user ने कौन से orders दिए हैं।

Basic Lookup Syntax
// Basic $lookup syntax db.collection.aggregate([ { $lookup: { from: "targetCollection", // जिस collection से join करना है localField: "localFieldName", // current collection का field foreignField: "foreignFieldName", // target collection का field as: "resultArrayName" // result में array का naam } } ])

🎯 Interactive Lookup Examples

1. Basic Lookup - Users के साथ उनके Orders

Query
// सभी users के साथ उनके orders find करें db.users.aggregate([ { $lookup: { from: "orders", // orders collection से join localField: "_id", // users की _id foreignField: "userId", // orders की userId as: "userOrders" // result array का naam } } ])

2. Lookup with Pipeline - Advanced Filtering

Query with Pipeline
// Users के साथ केवल 10000 से ज्यादा amount के orders db.users.aggregate([ { $lookup: { from: "orders", let: { "user_id": "$_id" }, // variable define करें pipeline: [ // custom pipeline { $match: { $expr: { $and: [ { $eq: ["$userId", "$$user_id"] }, { $gt: ["$amount", 10000] } // amount > 10000 ] } } }, { $project: { // केवल specific fields product: 1, amount: 1, _id: 0 } } ], as: "expensiveOrders" } } ])
📊 Result:

3. Multiple Lookups - एक से ज्यादा Collections

Multiple Collections Join
// Users + Orders + Categories (तीन collections join) db.users.aggregate([ { // पहली lookup - Orders $lookup: { from: "orders", localField: "_id", foreignField: "userId", as: "orders" } }, { // दूसरी lookup - Categories $lookup: { from: "categories", localField: "orders.categoryId", foreignField: "_id", as: "categories" } }, { $project: { name: 1, email: 1, totalOrders: { $size: "$orders" }, orders: 1, categories: 1 } } ])
📊 Result:

4. Lookup + Unwind - Array को Flatten करें

Lookup with $unwind
// हर order को अलग document बनाएं db.users.aggregate([ { $lookup: { from: "orders", localField: "_id", foreignField: "userId", as: "orders" } }, { $unwind: "$orders" // array को separate documents में convert }, { $project: { userName: "$name", userEmail: "$email", orderId: "$orders._id", product: "$orders.product", amount: "$orders.amount" } } ])

🔥 Common Use Cases & Patterns

कब use करें $lookup:

  • 🛒 E-commerce: Users के साथ उनके orders, products
  • 📝 Blog: Posts के साथ comments, authors
  • 🏢 Employee: Departments के साथ employees
  • 📚 School: Students के साथ courses, grades
  • 🏥 Hospital: Patients के साथ appointments, doctors
Performance Tips
// 1. हमेशा indexed fields पर join करें db.orders.createIndex({ "userId": 1 }) // 2. $match को $lookup से पहले use करें db.users.aggregate([ { $match: { "city": "Delhi" } }, // पहले filter करें { $lookup: { ... } } // फिर lookup करें ]) // 3. $project का use करके unnecessary fields remove करें db.users.aggregate([ { $lookup: { ... } }, { $project: { name: 1, orders.product: 1, // केवल जरूरी fields orders.amount: 1 } } ]) // 4. $limit का use करें बड़े datasets के लिए db.users.aggregate([ { $lookup: { ... } }, { $limit: 10 } // limit results ])
